AI Toolbox：多平台 AI 聊天增强 Chrome 扩展（终身制为主）

开发并维护一款 Chrome 扩展，为 ChatGPT/Claude/Gemini/Grok 四大家聊天界面统一增加文件夹管理、全文检索、提示词库、导出等生产力功能，按平台收费（月费/年费/终身制）。
赚钱逻辑
用户为提升多平台聊天历史的可检索性与复用效率付费；定价：单平台 9.99 美元/月、59 美元/年、99 美元终身，四平台捆绑终身 200 美元。实测收入以一次性终身购买为主，MRR 占比低。
收入证据
TrustMRR 2026-11-19 验证：近 30 天收入 24600 美元、MRR 1214 美元、活跃订阅 140 个；2026-10 单月 23300 美元；累计收入 140000 美元。

风险提示
1) 平台强依赖：ChatGPT/Claude/Gemini/Grok 任一改版 DOM 结构或上线原生文件夹/搜索/导出功能即失效；2) 单一渠道：Chrome Web Store 审核与分发垄断；3) 收入结构脆弱：终身制占比高导致 MRR 低、复购弱、估值折价；4) 维护负担：四平台并行适配、Manifest V3 迁移、浏览器内核更新均需持续投入。
第一步行动
在本地搭建最简 Chrome 扩展骨架（Manifest V3 + content script 注入），在 ChatGPT 网页版成功插入一个固定按钮并打印 DOM，跑通注入与选择器定位流程。
