autoclip 开源长转短视频工具接单/自用流水线

粘贴链接或上传本地长视频，自动生成最多 10 条带字幕、封面、标题、文案与标签的短视频及 ZIP 发布包；剪切渲染本地完成，支持抖音/小红书/TikTok/Reels/Shorts/B站/YouTube 画幅与时长规则；提供桌面端、Docker、CLI 与 MCP 服务器。
赚钱逻辑
靠接单服务变现：帮播客、课程、访谈类客户把长视频批量切成短视频包收费，或自建账号矩阵跑剪辑流水线获取流量变现。
收入证据
原信源未给出可核实的收入数据，谨慎评估。
启动成本
软件免费开源；首次本地安装下载约 220MB；文本模型成本实测约 0.09 元（1h43m 英文）、约 0.20 元（2h52m 中文）；云端转写另计约 0.1 元/小时音频（私密素材需走本地 Whisper）。
时间投入
实测同一台 Apple Silicon Mac：1h43m 素材约 7.5 分钟出 10 条；2h52m 素材约 29.5 分钟出 10 条。日常接单按单量排期，自建矩阵则需持续投入选题与发布时间。
风险提示
剪别人视频再发布涉及版权与平台规则（README 演示用第三方访谈亦声明仅作演示）；云端转写会上传音频，私密素材须走本地 Whisper；成本表仅为单机 3 次实测、不可作基准；桌面端仅支持 Apple Silicon Mac 与 Windows x64；无收入证据，属工具加服务机会而非已验证案例。
第一步行动
今天克隆 github.com/zhouxiaoka/autoclip，按 README 在本地（Apple Silicon Mac 或 Windows x64）跑通一条 10 分钟内的测试视频，确认全链路耗时与成本。
匹配理由 · 🎯 85
可直接复用 AI 工具与自动化流水线经验，结合现有内容站选题能力快速跑通接单或自用矩阵。
